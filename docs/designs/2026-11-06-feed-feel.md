# Design: Feed feel (W2): fonts, placeholders, motion, haptics, accessibility

- Author: Claude (thread "Polish feed feel and animations"), asked for by Maxwell Rhinelander
- Date: 2026-11-06
- Status: Draft

## Problem

Maxwell got the app running on 2026-11-06 and asked for a round of UX polish. This is workstream
W2 in [roadmap.md](../roadmap.md) Phase 1.5: the feed should feel like the concept art (real
fonts, board-shaped loading states instead of bare spinners, friendly empty and offline states),
paging and likes/saves should give clear feedback, and every card should work with VoiceOver,
Dynamic Type and Reduce Motion without text ever covering the animal (D-010).

## Where it goes

Features and `App/Theme` only. W2 edits only the files it owns (roadmap W2 list).

| File | Change |
| --- | --- |
| `Resources/Fonts/` (new) | Fredoka 500/600 and Nunito Sans 400/600/700/800 as `.ttf`, plus both `OFL-*.txt` licences and a `README.md` saying where they came from. |
| `project.yml` | `UIAppFonts` lists the six files. |
| `App/Theme.swift` | Font names point at the bundled PostScript names (one `Theme.FontName` enum, so tests and views share them). Adds `Theme.Motion` (spring and fade constants) so durations live in one place. Moves `BoardPanel` out to Components (it is shared UI, not theme). |
| `Features/Components/BoardPlaceholder.swift` (new) | A board-shaped skeleton (wood frame, green panel, parchment bars) with a slow shimmer, static under Reduce Motion. Also a plain `ShimmerFill` that W1's `FullBleedImage` can use for its loading phase instead of `ProgressView`. |
| `Features/Feed/FeedStatusView.swift` (new) | The page shown when there are no cards: placeholder board while loading, or an empty state (binoculars and "Change your branches on the Tree tab"; a jump to the Tree tab would need `RootView`, which W3 owns, so text only) or an offline state with a **Try again** button that calls `model.restart`. |
| `Features/Feed/FeedView.swift` | Uses `FeedStatusView`; `scrollTransition` on cards (slight scale and dim as a card leaves; off under Reduce Motion); `sensoryFeedback` for like, save and unsave; a short "Saved to Met" / "Removed" toast after a long-press save; double-tap moved to `simultaneousGesture` so single taps on buttons and the board are not delayed; VoiceOver custom actions on every card (Like, Save, Species details) so no gesture is required. |

No changes to Services, Stores or Models.

## Data flow

Unchanged: `FeedViewModel.cards` → `FeedView` → card views. Haptic and toast triggers are local
`@State` in `FeedView` (UI feedback only, no business rule). The feed state the view needs comes
from `FeedViewModel` (W1-owned), see "Asks of W1".

## New contracts

None in Models, persisted keys or JSON. No third-party dependency.

**Asks of W1** (they own `FeedViewModel.swift` and `FullBleedImage`):

1. Replace `emptyMessage: String?` with a small enum, e.g.
   `enum FeedNotice { case noMatches, offline }`, so the view picks the empty or offline layout
   without matching on strings. Until it lands, `FeedStatusView` treats any message as "empty"
   and shows the message text plus Try again.
2. Use `ShimmerFill` in `FullBleedImage`'s loading phase (one-line change in their file).
3. Step 5: position/count on the card payload. `FeedView` switches over once it lands
   (W1 keeps `positions` until then).

## Content rules

No new content source and no animal content in Swift. All new strings are UI chrome ("Try
again", "Saved to Met", "Finding the next animal…"). Fonts are SIL OFL 1.1 (neither has a
Reserved Font Name). The `.ttf` files are the same `.woff2` files already in
`docs/design/concept-art/fonts/`, decompressed to TrueType with `fontTools` (container
conversion only, no glyph changes); the command is in `Resources/Fonts/README.md`. These are
latin subsets, which cover Latin-1 and Latin Extended-A; other glyphs fall back to the system
font.

## Tests

- `ThemeFontTests`: every `Theme.FontName` loads with `UIFont(name:size:)` in the app bundle
  (catches a missing `UIAppFonts` entry or a wrong PostScript name).
- No pure logic changes, so no service tests change. Accessibility and motion are checked by
  hand on the simulator (VoiceOver, largest accessibility text size, Reduce Motion on) and
  listed in the PR.

## Open questions

- Nunito Sans has no italic in the bundled files, so scientific names (italic by convention)
  would lose their slant. Proposal: keep scientific names in the system font italic until an
  italic face is added. Alternative: bundle Nunito Sans Italic later from the Google Fonts
  release (needs network access the cloud environment doesn't have).
- Haptics: like = `.impact(weight: .light)`, save = `.success`, unsave = `.selection`. No haptic
  on every page turn (it gets tiring in a doom-scroll); say if you want one on each new species.
